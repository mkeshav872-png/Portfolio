## 🚀 Run Locally (Apne Computer Par Chalao)

```bash
# 1️⃣ Repository clone karo
git clone https://github.com/mkeshav872-png/Portfolio.git

# 2️⃣ Folder ke andar jao
cd Portfolio

# 3️⃣ index.html ko browser mein kholo (double click karna kaafi hai)
```

> 🌐 Internet on rakhna, kyunki fonts aur animation libraries CDN se load hoti hain.

---

## 🌍 Deploy on GitHub Pages

1. 📂 Repository ke **Settings** mein jao
2. 📄 Left side mein **Pages** par click karo
3. 🌿 **Source** mein `Deploy from a branch` chuno
4. 🔀 Branch `main` aur folder `/ (root)` select karo, phir **Save**
5. ⏳ 1-2 minute baad tumhari site live ho jayegi 🎉
